# 踩过的坑（派发前过一眼）

| 坑 | 现象 | 做法 |
|---|---|---|
| 脱离启动执行角色 | `( cmd & )` / nohup 启动后终端看不到、完成没通知，只能手动轮询 | 用主控代理自带的后台任务功能运行 `run_role.sh` |
| CLI 等 stdin | 后台运行时卡在 "Reading additional input from stdin" 一整夜 | 一律 `< /dev/null`（run_role.sh 已处理） |
| 无头设计角色不能跑命令 | 设计角色花半小时爬资源目录、导出图标失败 | 主控提前把图标、截图、旧文案导出到设计目录，任务书写明「不运行命令」 |
| 额度用完 | 执行角色几秒就退出，日志里一句 quota | 配好备用模型；run_role.sh 识别到短日志 + 额度报错就自动换 |
| CLI 记住 --model | 一次指定模型后，以后都默认用它 | 适配器跑完还原配置（cursor-agent 适配器已处理） |
| 并发会话混改动 | 提交时混进别人的文件 | 每个任务 `scope.py start/end`，验收前核对清单 |
| 两个编码任务同时跑 | 互相覆盖文件、编译互相打断 | 串行排队：`a && b` 放进同一个后台任务 |
| 重写丢内容 | 新页面少了一句提示、一个按钮 | 对照**最初**版本的文案逐条核对；`design_lint.py --source` 自动查 |
| 设计稿加戏 | 多出原页面没有的徽标、相对时间、统计 | 任务书写死「内容不增不减」，lint `--base` 查新增文本 |
| 骨架和真实布局不一致 | 加载时出现基类通用骨架，数据回来后跳成卡片 | 关掉通用骨架，用和真实布局同形状的骨架；验收时专门看加载态 |
| 安全区被吃掉 | 底部按钮压在 Home 指示条上 | 查宿主是否清空了 safe area，从根上把 inset 传进来，不硬编码 34 |
| 共享组件改动波及 | 改一个页面的样式，另外 6 个页面也变了 | 审查时列出共享组件的所有使用方，汇报里点名让用户去看 |
| 主控替设计出点子 | 设计稿变成主控的想法，设计角色只是画图 | 任务书只写用户原话和事实，方案由设计角色出 |
