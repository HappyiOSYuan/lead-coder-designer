# AGENTS.md — MyApp 协作约定

本文件给所有代理读。项目规则的唯一来源是 `.cursor/rules/*.mdc` 和 `.cursor/skills/*/SKILL.md`；本文件只做索引和协作约定。

## 分工
| 角色 | 负责 | 不做 |
|---|---|---|
| 主控 | 定位代码、写任务书、审 diff、编译把关、模拟器截图验收、与用户沟通 | 不直接改工程代码 |
| 编码 | 工程代码的修改、编译 | 不做设计决策 |
| 设计 | HTML 设计稿、动效演示、交付说明（handoff） | 不改工程代码；设计稿只写到 `DesignMockups/`（版本库已忽略） |

## 设计约束
- 平台风格：Apple HIG，界面能直接用 SwiftUI 实现；基准机型宽 402pt；页面左右边距、列表左缩进 16pt。
- 只做浅色；系统导航栏（主题色实底、白字、返回箭头），不做自定义标题栏。
- 玻璃材质只用在导航/操控层（Tab bar、Toolbar、Sheet 外壳、浮动操作条），内容卡片不用，不叠两层；用了要写低版本和「降低透明度」回退。
- 内容不增不减；图标只用工程现有图标（主控导出到设计目录 `icons/`）。
- 动效：进出场 ease-out，常规 UI ≤300ms，不用 ease-in，不从 scale 0 起；handoff 写明每个动效的曲线和时长。

### 方向确认门槛
新视觉 / 大改版 / 「优化设计」：第一轮只出 2–3 个方向，摆出来就停，等用户选；选定后主控把用户原话写进 `direction-approved.md`。只改细节的修订不走。

### 反模板装饰（画板内禁止）
全大写英文小标签、中英混排标题、「A · B · C」串词、末尾装饰「→」、假序号、渐变、emoji 图标、卡片左彩条、手画图标、编造统计。

### 交稿自检
`python3 -I <skill>/scripts/design_lint.py DesignMockups/<目录> [--base <原稿>] [--source <旧代码目录>]`，error 必须为 0。

## 改代码前必读的规则（按任务挑 1–3 条）
- 总是适用：自检、Swift 语法、OC/Swift 互调、布局约束（SnapKit/Masonry 贴 safeArea）、工程文件安全修改、第三方库补丁
- SwiftUI 宿主 / 加载骨架：宿主 VC、骨架、表单加载态
- 其他：分页控制器、模型解析、通知 ……

## 关键约定（摘要）
- 加载数据后才显示的页面用骨架（和真实布局同形状），不用转圈 HUD。
- 改工程文件前先备份，改完 `plutil -lint`。
- 改第三方库源码必须在依赖管理的安装钩子里留幂等补丁。
- 小改动不编译（用户编译）；大改动或新增文件要编译，用编译汇总脚本。

## 每个任务的收尾清单（逐条做完再报告）
1. 只改任务范围内的文件；范围外问题写进报告，不顺手改。
2. 新建文件：加入 App target 并 `svn add`。
3. 报告、草稿、日志不得写进工程目录（设计稿只能写 `DesignMockups/`）。
4. 跑 `review_diff.py <改动目录>`，error 必须为 0。
5. 报告列出：改动文件清单、用到的规则、编译结果、未完成或跳过的项及原因。
6. 不执行 `svn commit`。
